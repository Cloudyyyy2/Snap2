## Problem Statement
Snap2's offline core (`OFFLINE_ONLY=1`, named `ocr-exports/run-*` folders, interactive bounding-box highlights, `"What is this for?"` object fallback, Today's Reminders spotlight) is built and tested (`90/90` tests). To elevate the live phone + host demo into an unforgettable experience, we want to add three capabilities:
1. **Live OCR X-Ray Scrubber:** Scrub through every saved stage PNG (`01_original` -> `02_deskewed` -> `03b_background_flattened` -> `03c_ruled_lines_removed` -> `04_contrast_enhanced` -> `05_adaptive_binary` -> `06_line_*`) directly inside the PWA.
2. **Background Random-Window Phone Push + Snap-to-Verify:** A host-side background scheduler that fires randomized lock-screen Web Push nudges for Today's Reminders even when the browser tab is closed, plus optional photo proof when marking a reminder done.
3. **Receipt, Recipe & Fridge Memory Modes:** Offline `localReminderParser.ts` modes for Receipts (totals + return/warranty reminders), Recipes (ingredients -> checkable shopping list), and Fridge/Object photos (expiry/usage reminders).

## What Makes This Cool
- **Visible AI thinking:** Dragging a slider on your phone to watch ruled notebook lines vanish and cursive handwriting sharpen live from the host's `ocr-exports/` folder.
- **Zero-cloud lock-screen nudges:** Your phone buzzes at surprise times with today's reminders even with the app closed, and you can snap a completion photo as visual proof.
- **One capture engine, four real-life jobs:** Grocery/task lists, receipts, recipe cards, and fridge/object photos all work 100% offline.

## Constraints
- **100% Offline / In-House:** Zero internet or cloud AI calls (`OFFLINE_ONLY=1`).
- **Preserve Existing Core:** Keep all `90/90` existing unit tests green.
- **PWA + Mobile Camera:** Works over `adb reverse` or LAN HTTPS (`server.ts`).

## Approaches Considered
### Approach A: Phased Showcase (#1 + #2 First, Then #3) *(Selected)*
Ship **Phase 1 (Live OCR X-Ray Scrubber + Background Random Push + Snap-to-Verify)** first using existing `/api/ocr-exports` and `data/push-subscriptions.json`, verify live on phone, then ship **Phase 2 (Receipt / Recipe / Fridge parser modes)** in `localReminderParser.ts`.
### Approach B: Unified Single-Pass Build
Build all three features in one large pass. *Deferred:* higher risk for live demo readiness before Phase 1 is verified on the phone.

## Recommended Approach
**Phase 1 — Live OCR X-Ray & Background Push (`M`, `Low` risk):**
1. **OCR X-Ray Scrubber (`src/components/OcrXRayViewer.tsx`, used in `UploadModal.tsx` & `OcrStudio.tsx`):**
   - Fetch `/api/ocr-exports` (or the current `exportDirName`) and render a stage-slider + step labels (`Original` -> `Deskewed` -> `Flattened` -> `Lines Removed` -> `Contrast` -> `Binary` -> `Line Crops`) using `/ocr-exports/:run/:file`.
2. **Host-Side Reminder Sync & Random-Window Push Scheduler (`server.ts`, `src/App.tsx`):**
   - Sync active Today's Reminders to `data/active-reminders.json` on the host (`POST /api/reminders/sync`) so `server.ts` knows what's due even when the phone tab is closed.
   - Run a lightweight background interval in `server.ts` that picks a random due-today reminder inside configurable active hours and fires Web Push via `sendPushToTargets` (with cooldown so it doesn't spam).
3. **Snap-to-Verify Completion (`src/components/ReminderInspector.tsx`, `src/types.ts`):**
   - Add an optional `completionImage?: string` on `Reminder` and a **"Snap Proof to Complete"** button in `ReminderInspector.tsx` using `CameraCapture.tsx`.

**Phase 2 — Receipt / Recipe / Fridge Modes (`S`, `Low` risk):**
1. **Capture Mode Chips (`UploadModal.tsx`, `OcrStudio.tsx`, `server/localReminderParser.ts`):**
   - Add optional mode hints (`auto`, `grocery`, `receipt`, `recipe`, `fridge`) passed to `parseReminderLocally`:
     - `receipt`: extracts total/merchant + sets a return/warranty/expense reminder.
     - `recipe`: extracts ingredient lines into a checkable shopping `checklist`.
     - `fridge`: pairs with `"What is this for?"` / expiry quick-presets (`Use in 2 days`, `Use this week`).

## Success Criteria
- Scrubber smoothly previews all stage PNGs for a scan inside the PWA on mobile and desktop.
- Host server fires a Web Push notification to the phone even when the browser tab is closed.
- User can attach a completion photo when finishing a reminder.
- Receipt, Recipe, and Fridge modes produce structured checklists/reminders offline.
- `npm run lint` and `npm run test:unit` pass with zero errors.
